# Callouts

> [!NOTE]
> Note body.

> [!TIP]
> Tip body.

> [!IMPORTANT]
> Important body.

> [!WARNING]
> Warning body.

> [!CAUTION]
>
> Caution body, the marker on a paragraph of its own.

> ## [!TIP]
> A heading holding the marker is not a callout.

> ```
> [!WARNING]
> ```
>
> A code block holding the marker is not a callout.

> `[!TIP]`
> A marker in a code span is not a callout.

> **[!NOTE]**
> A bold marker is not a callout.

> \[!NOTE]
> An escaped marker is not a callout.
