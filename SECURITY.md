# Security policy

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/boudou/Markloom/security/advisories/new)
rather than a public issue. Include steps to reproduce and the affected version.

Markloom renders untrusted Markdown, so reports about sanitisation, the Electron
file-access boundary (`electron/main.cjs`) or the export pipeline are especially welcome.
