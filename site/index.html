Write in Markdown. Send it as Word, diagrams included.

Markloom is a free, open-source editor with live Mermaid diagrams and clean export to Word, PDF and HTML. Your documents stay on your computer.

Try it in your browser Download the desktop app

No account, nothing to install. Windows, macOS, Linux and the web. MIT licence.

{{shot split-view | Markloom's split view: a Markdown document on the left, and on the right its live preview with a callout and a Mermaid flowchart}}

This is the document you get when you press Try it. Change it, break the diagram, export it.

Diagrams are part of the document

Write a fenced mermaid block and the drawing appears beside it as you type. Flowcharts, sequence diagrams, Gantt charts, class diagrams, mind maps: if Mermaid can draw it, it is in your preview, in rich text and in every export.

When the syntax is wrong, the message gives the line in your document, not a line inside the diagram, and a button takes you there.

Export for people who don't use Markdown

Your reviewer wants Word. Your manager wants a PDF. One key, Ctrl E, gives them a file with the diagrams, images and tables already in it, and you keep the Markdown.

Word (.docx)
Editable, with real headings, lists and tables. Diagrams are embedded as images.
PDF
Diagrams stay as vector graphics.
Web page
One standalone HTML file with everything inside it.
Image
PNG pages, a .zip of them, or one long image.
Portable Markdown
A single .md file with its images embedded.

Before it writes anything, Markloom checks for diagrams that won't draw and images it can't find, and lists them by line. How the Word export works.

Rich text that leaves your file alone

Visual Markdown editors often reformat a file when they save. Markloom's rich-text mode rewrites only the blocks you touched, so your list markers, line wraps and tables stay as you typed them, and a one-word fix is a one-line commit.

@@ release-plan.md @@ The order we ship in, and who signs off. -Publish the draft on Friday.+Publish the final PDF on Friday.  * Write the notes * Add the diagram

Your folder, on your disk

Open a folder and work on the files in it. There are no accounts, no uploads and no database to import into, so Git, Dropbox and your other editors keep working. Ctrl P opens a file by name and Ctrl Shift F searches all of them.

Need it somewhere Markdown doesn't reach? Copy as rich text pastes the document, formatted and with its diagrams, into an email, Google Docs or Confluence.

Questions

Is it really free?

Yes. It is MIT licensed, with no paid tier, no account and no trial.

Where do my documents go?

Nowhere. The web version is a static page that runs in your browser, and files are read and written on your computer. If you allow it, the web version counts page views with Google Analytics. It asks first, and the desktop app has no analytics.

Which browsers work?

Chrome, Edge and other Chromium browsers do everything. Firefox and Safari don't offer the file access Markloom uses, so there you can write and export but not open or save files. The desktop app has no such limit.

Why does Windows or macOS warn me about the installer?

The installers aren't code-signed yet. You can read the code, build it yourself, or follow the steps for the first run. Windows 11's Smart App Control has no override, so there the web version is the easy way in.

What doesn't it do?

Markloom is built around one document going to other people: diagrams, review copies, exports. It has no plugins, graph view or sync.
